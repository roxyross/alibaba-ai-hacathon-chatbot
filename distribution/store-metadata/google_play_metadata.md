### Full Description (4000 chars max)
Turn your ideas into autonomous actions with Roxy AI — the personal AI agent platform built for developers, creators, and professionals.

Roxy is not just a chatbot. It is a full-featured agentic runtime that bridges natural language with real-world computing power across your desktop and mobile devices.

🚀 **CORE CAPABILITIES:**
• **Autonomous Task Orchestration:** Hand off multi-step research, writing, debugging, and file manipulation. Roxy creates deterministic plans, executes sandboxed tools, and reports verified results.
• **Mobile Code Studio:** Experience modern IDE workflows on mobile. Inspect project files, view syntax-highlighted code, trigger unit tests, and resolve issues on the go.
• **Natural Voice Sessions:** Engage in voice conversations with fluid conversational intelligence powered by Google Gemini and advanced LLM runtimes.
• **Scheduled Reminders & Jobs:** Set recurring automations, cron tasks, and calendar reminders with rich audio notifications and custom ringtone chimes.
• **Multi-Device Fleet:** Seamlessly pair your Android device with your desktop workstation. Monitor system load, manage paired companions, and revoke device sessions anytime.
• **Knowledge Vault & Memory:** Query your private documents, financial summaries, and notes through high-speed semantic retrieval.
• **Enterprise Security:** Tokens and identity keys are secured locally via Android Keystore and EncryptedSharedPreferences (AES-256).

### Google Play Data Safety Declaration

#### 1. Data Collection & Sharing
- **Does your app collect or share user data?** Yes.
- **Is all user data encrypted in transit?** Yes (TLS 1.3 / HTTPS).
- **Do you provide a way for users to request data deletion?** Yes (in-app and via `https://app.roxy.ai/account/delete`).

#### 2. Data Types Collected
- **Personal Info:** Email address (Account management & authentication).
- **Audio Files:** Voice recordings (Ephemeral processing during user-activated voice chat; never sold or shared).
- **App Activity:** In-app actions and tool execution logs (Analytics and audit security).
- **Device Identifiers:** Hardware Device ID (Device pairing and push notification delivery).

#### 3. Security Practices
- Data encrypted in transit using industry-standard protocols.
- Independent third-party security audits conducted.
- Strict confirmation gating on destructive system actions.
