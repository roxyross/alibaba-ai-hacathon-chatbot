### Description
Roxy AI is your autonomous personal artificial intelligence companion, designed to execute real work across your devices. From full-stack software development in Code Studio to multi-turn voice conversations, calendar scheduling, and automated task execution, Roxy bridges high-level intelligence with real-world computer action.

**KEY FEATURES:**
• **Autonomous Agent Runtime:** Delegate complex multi-step research, writing, and coding missions.
• **Mobile Code Studio:** Inspect workspaces, edit code, review git diffs, and orchestrate tests directly from your iPhone or iPad.
• **Natural Real-Time Voice:** Converse with low-latency bidirectional voice intelligence powered by Google Gemini 2.0 Flash and Gemma models.
• **Cross-Device Continuity:** Start a task on your Mac or Windows PC, check progress on your iPhone, and receive native push notifications upon completion.
• **Knowledge Vault:** Ingest documents, notes, and research into a private semantic memory index accessible whenever you need it.
• **Secure Hardware Enclave:** Your tokens and credentials are encrypted using Apple Keychain technology. Zero unauthenticated access.
